IMPORTANT — NETLIFY DEPLOY METHOD

Do NOT upload this ZIP using Netlify's "Dropped files" / Netlify Drop screen.

Extract this ZIP, upload the project contents to a PRIVATE GitHub repository, then connect that repository to your existing Netlify site. Netlify will build the functions using the included netlify.toml.

Follow README_DEPLOY_AND_SELL.md for exact steps and required environment variables.
